1"""Single-player outlook: a hand's own chances of reaching ready and of winning. 

2 

3A draw-only abstraction of the rest of the hand. Only this player draws, taking 

4tiles it cannot see; nobody calls, nobody discards into a win, and there are no 

5kans or interruptions, so the only win is a tsumo. The player is assumed to play 

6the abstraction perfectly, choosing at every draw the discard that maximises the 

7measure being reported. 

8 

9Draws are taken **with** replacement: every draw sees the same pool, so a kind 

10already drawn is no less likely to come again. That keeps a hand's value 

11independent of how many draws have gone before, which is what lets one pass 

12compute the whole curve. It understates a little -- a wait truly thins the pool 

13as the hand goes on -- in the same direction as the search restriction below. 

14 

15This is a hand-potential measure, not a game model: defence, calls, and the 

16opponents are outside it. It reports two probabilities as curves over the draws 

17still to come, both cumulative and both absorbing -- the chance of having reached 

18ready, and the chance of having won, on or before each draw. 

19 

20Each measure is maximised by its own line of play, so the ready curve is the best 

21achievable readiness and the win curve the best achievable win rate; neither is 

22the other's by-product. Winning is judged on shape alone, so a hand that could 

23not legally win for want of a yaku still counts as won here. 

24 

25Only draws that shorten the distance to ready are searched, and by default only 

26the single most promising hand is kept per such draw. Sideways exchanges that 

27trade one wait for a wider one of the same distance are therefore declined, so 

28every figure reported is a floor on what perfect play would achieve, not an 

29estimate of it. 

30"""

50"""Hands the reachable-hand graph cache holds, summed over its entries. 

51 

52Counted in hands rather than in entries because entries differ hugely in size: a 

53ready hand's graph is a single hand, one far from ready can be hundreds. Bounding 

54the count of entries would leave residency free to vary by orders of magnitude, 

55which matters when a caller runs a pool of worker processes. 

56 

57The graph itself depends on the hand alone, never on which tiles are visible, so 

58one entry serves every game position that reaches the same shape. 

59"""

65@dataclass(frozen=True) 

66class Valuation: 

67 """The table as it stands, for pricing a hand's winning completions. 

68 

69 The context is frozen at the moment of asking: the indicators are the ones 

70 already turned, and no later reveal, no ura, and no riichi is supposed. A 

71 completion is priced as a self-draw, which is the only win the abstraction 

72 admits, so a concealed hand always carries at least the self-draw yaku. 

73 Table bonuses -- the repeat counter and the deposits on the table -- are left 

74 out, since they belong to the table rather than to the hand. 

75 

76 Attributes: 

77 rules: The rules the completion is scored under. 

78 melds: The called sets the hand holds, which fix what it can still score. 

79 dora_indicators: The indicators turned so far. 

80 round_wind: The wind of the round. 

81 seat_wind: The wind of the seat. 

82 red_fives: Red copies held per kind, since a count of tiles by kind 

83 cannot carry the marking on its own. Only fives may be marked. One 

84 valuation serves every candidate of a discard sweep, so a candidate 

85 that cuts its only marked five is priced with the red in the pond 

86 rather than rejected. 

87 """

119@dataclass(frozen=True) 

120class _Graph: 

121 """The hands reachable from a starting hand, and how each is reached. 

122 

123 States are held by index so the evaluation sweep can address them by 

124 position. A draw that improves nothing leaves no edge: the tile is discarded 

125 again and the hand stays where it is, which the sweep models as staying put. 

126 

127 Attributes: 

128 counts: Each state's concealed counts by kind. 

129 ready: Whether each state is already ready. 

130 wins: Each state's winning draws, by kind. 

131 moves: Each state's improving draws, as a kind with the states it can 

132 leave behind. 

133 """ 

134 

135 counts: tuple[tuple[int, ...], ...] 

136 ready: tuple[bool, ...] 

137 wins: tuple[tuple[int, ...], ...] 

138 moves: tuple[tuple[tuple[int, tuple[int, ...]], ...], ...]

141def _acceptance_breadth(counts: list[int], num_melds: int, kinds: tuple[TileKind, ...], base: int) -> int: 

142 """How many draws would lower this hand's shanten, ignoring visible tiles.""" 

143 drawable = [kind for kind in kinds if counts[kind] < TILES_PER_KIND] 

144 after = draw_shantens(counts, num_melds, drawable) 

145 return sum(TILES_PER_KIND - counts[kind] for kind in drawable if after[kind] < base)

148def _landings( 

149 counts: list[int], 

150 num_melds: int, 

151 kinds: tuple[TileKind, ...], 

152 drawn: TileKind, 

153 improved: int, 

154 beam: int | None, 

155) -> list[tuple[int, ...]]: 

156 """The hands a shanten-lowering draw can leave behind, best first if capped.""" 

157 held = [kind for kind in kinds if counts[kind]] 

158 after = discard_shantens(counts, num_melds, held) 

159 landed: list[tuple[int, ...]] = [] 

160 for kind, shanten in after.items(): 

161 if shanten != improved or kind == drawn: 

162 continue 

163 counts[kind] -= 1 

164 landed.append(tuple(counts)) 

165 counts[kind] += 1 

166 if beam is None or len(landed) <= beam: 

167 return landed 

168 landed.sort(key=lambda state: -_acceptance_breadth(list(state), num_melds, kinds, improved)) 

169 return landed[:beam]

172def _expand( 

173 state: tuple[int, ...], 

174 num_melds: int, 

175 kinds: tuple[TileKind, ...], 

176 beam: int | None, 

177 *, 

178 deepen: bool, 

179) -> tuple[int, list[int], list[tuple[int, list[tuple[int, ...]]]]]: 

180 """One hand's shanten, its winning draws, and its improving draws' landings. 

181 

182 With ``deepen`` unset the landings are skipped: the hand sits at the horizon, 

183 where no further improvement could be drawn on in time to matter. 

184 """ 

185 counts = list(state) 

186 base = shanten_counts(counts, num_melds) 

187 drawable = [kind for kind in kinds if counts[kind] < TILES_PER_KIND] 

188 after = draw_shantens(counts, num_melds, drawable) 

189 wins: list[int] = [] 

190 moves: list[tuple[int, list[tuple[int, ...]]]] = [] 

191 for kind in drawable: 

192 improved = after[kind] 

193 if improved == _COMPLETE: 

194 wins.append(int(kind)) 

195 continue 

196 if improved >= base or not deepen: 

197 continue 

198 counts[kind] += 1 

199 landed = _landings(counts, num_melds, kinds, kind, improved, beam) 

200 counts[kind] -= 1 

201 if landed: 

202 moves.append((int(kind), landed)) 

203 return base, wins, moves

206def _build(state: tuple[int, ...], num_melds: int, player_count: int, depth: int, beam: int | None) -> _Graph: 

207 """Every hand reachable from this one by ``depth`` shanten-lowering draws. 

208 

209 Built without reference to any visible tiles, so the same graph serves every 

210 game position holding this shape; the tiles actually left to draw enter only 

211 as weights when the graph is evaluated. 

212 """ 

213 kinds = kinds_in_play(player_count) 

214 index = {state: 0} 

215 order = [state] 

216 levels = [0] 

217 ready: list[bool] = [] 

218 wins: list[tuple[int, ...]] = [] 

219 moves: list[tuple[tuple[int, tuple[int, ...]], ...]] = [] 

220 cursor = 0 

221 while cursor < len(order): 

222 level = levels[cursor] 

223 base, won, stepped = _expand(order[cursor], num_melds, kinds, beam, deepen=level < depth) 

224 ready.append(base <= _READY) 

225 wins.append(tuple(won)) 

226 edges: list[tuple[int, tuple[int, ...]]] = [] 

227 for kind, landed in stepped: 

228 targets = [] 

229 for hand in landed: 

230 if hand not in index: 

231 index[hand] = len(order) 

232 order.append(hand) 

233 levels.append(level + 1) 

234 targets.append(index[hand]) 

235 edges.append((kind, tuple(targets))) 

236 moves.append(tuple(edges)) 

237 cursor += 1 

238 return _Graph(tuple(order), tuple(ready), tuple(wins), tuple(moves))

241class _GraphCache: 

242 """The built graphs, bounded by how many hands they hold between them. 

243 

244 Oldest entries go first once the bound is passed, and a single entry larger 

245 than the whole bound is simply kept alone rather than evicting itself. 

246 """ 

247 

248 def __init__(self, limit: int) -> None: 

249 self._limit = limit 

250 self._held: dict[tuple[object, ...], _Graph] = {} 

251 self._states = 0 

252 

253 def get(self, key: tuple[object, ...], build: Callable[[], _Graph]) -> _Graph: 

254 """The cached graph for this key, building and storing it if absent.""" 

255 found = self._held.get(key) 

256 if found is not None: 

257 return found 

258 built = build() 

259 self._held[key] = built 

260 self._states += len(built.counts) 

261 while self._states > self._limit and len(self._held) > 1: 

262 self._states -= len(self._held.pop(next(iter(self._held))).counts) 

263 return built

275def _unseen(graph: _Graph, visible: Sequence[int], kinds: tuple[TileKind, ...]) -> tuple[list[list[int]], int]: 

276 """Copies of each kind still unseen from every hand, and the starting total. 

277 

278 Only the hand actually held has to square with the visible counts. The graph 

279 is built without them, so it can hold hands that would need a fifth copy of 

280 something already accounted for; those simply run dry, and the draw that 

281 would reach them carries no weight. 

282 

283 Raises: 

284 ValueError: If a kind's visible copies plus the held hand's own exceed four. 

285 """ 

286 pools: list[list[int]] = [] 

287 for index, counts in enumerate(graph.counts): 

288 pool = [0] * len(counts) 

289 for kind in kinds: 

290 left = TILES_PER_KIND - visible[kind] - counts[kind] 

291 if left < 0 and not index: 

292 raise ValueError(f"kind {TileKind(kind)} has more copies visible and held than exist") 

293 pool[kind] = max(left, 0) 

294 pools.append(pool) 

295 return pools, sum(pools[0])

298def _sweep(graph: _Graph, pools: list[list[int]], total: int, later: list[float], *, winning: bool) -> list[float]: 

299 """One draw's worth of value, given the value of every state one draw on. 

300 

301 Every draw that neither wins nor improves is thrown straight back, leaving the 

302 hand where it was, so the whole residual mass carries the staying value. The 

303 same staying value also floors each improving draw, because keeping the drawn 

304 tile is never forced. 

305 

306 Every hand here holds the same number of tiles, so every hand leaves the same 

307 number unseen and the divisor is the one pool total throughout. 

308 """ 

309 values = [0.0] * len(graph.counts) 

310 for index, pool in enumerate(pools): 

311 if not winning and graph.ready[index]: 

312 values[index] = 1.0 

313 continue 

314 held = later[index] 

315 drawn = 0 

316 value = 0.0 

317 if winning: 

318 # Only a ready hand has a winning draw, and the ready measure has 

319 # already answered for those, so this mass belongs to the win curve. 

320 for kind in graph.wins[index]: 

321 drawn += pool[kind] 

322 value += pool[kind] 

323 for kind, targets in graph.moves[index]: 

324 drawn += pool[kind] 

325 value += pool[kind] * max(held, *(later[target] for target in targets)) 

326 values[index] = (value + (total - drawn) * held) / total 

327 return values

330def _completed(state: tuple[int, ...], drawn: int, valuation: Valuation) -> Hand: 

331 """The hand this state becomes when the drawn kind completes it. 

332 

333 Red copies are placed among the tiles already held, never among the draw: 

334 the pool is counted by kind, so which copy arrives is not modelled. That 

335 also guarantees a plain copy of the drawn kind for the win to point at. 

336 """ 

337 tiles: list[Tile] = [] 

338 for kind, copies in enumerate(state): 

339 reds = min(valuation.red_fives[kind], copies) if valuation.red_fives else 0 

340 tiles.extend(Tile(TileKind(kind), red=True) for _ in range(reds)) 

341 tiles.extend(Tile(TileKind(kind)) for _ in range(copies - reds)) 

342 tiles.append(Tile(TileKind(drawn))) 

343 return Hand(tuple(tiles), valuation.melds)

346def _value(state: tuple[int, ...], drawn: int, valuation: Valuation, memo: dict[tuple, float]) -> float: 

347 """What this completion pays, or nothing when it carries no yaku to win on.""" 

348 key = (state, drawn) 

349 if key in memo: 

350 return memo[key] 

351 context = WinContext( 

352 rules=valuation.rules, 

353 round_wind=valuation.round_wind, 

354 seat_wind=valuation.seat_wind, 

355 is_tsumo=True, 

356 dora_indicators=valuation.dora_indicators, 

357 ) 

358 try: 

359 worth = float(score(_completed(state, drawn, valuation), Tile(TileKind(drawn)), context).payment.total) 

360 except ScoringError: 

361 worth = 0.0 

362 memo[key] = worth 

363 return worth

366def _points_sweep( 

367 graph: _Graph, 

368 pools: list[list[int]], 

369 total: int, 

370 later: tuple[list[float], list[float]], 

371 worth: list[dict[int, float]], 

372) -> tuple[list[float], list[float]]: 

373 """One draw of expected points, carrying the win odds of the line that earns it. 

374 

375 The choice at each improving draw is the one that maximises points expected, 

376 which is a third optimum alongside the two the probability curves report. The 

377 win odds ride along under that same choice, so dividing one by the other gives 

378 what a win is worth given that it happens. 

379 """ 

380 later_points, later_wins = later 

381 points = [0.0] * len(graph.counts) 

382 wins = [0.0] * len(graph.counts) 

383 for index, pool in enumerate(pools): 

384 held_points, held_wins = later_points[index], later_wins[index] 

385 drawn = 0 

386 earned = 0.0 

387 won = 0.0 

388 for kind in graph.wins[index]: 

389 drawn += pool[kind] 

390 earned += pool[kind] * worth[index][kind] 

391 won += pool[kind] 

392 for kind, targets in graph.moves[index]: 

393 drawn += pool[kind] 

394 best_points, best_wins = held_points, held_wins 

395 for target in targets: 

396 if later_points[target] > best_points: 

397 best_points, best_wins = later_points[target], later_wins[target] 

398 earned += pool[kind] * best_points 

399 won += pool[kind] * best_wins 

400 points[index] = (earned + (total - drawn) * held_points) / total 

401 wins[index] = (won + (total - drawn) * held_wins) / total 

402 return points, wins

405def _points_curve( 

406 graph: _Graph, 

407 pools: list[list[int]], 

408 total: int, 

409 horizon: int, 

410 valuation: Valuation, 

411 memo: dict[tuple, float], 

412) -> tuple[float, ...]: 

413 """What a win is worth given it happens, over the whole draws-remaining curve.""" 

414 worth = [ 

415 {kind: _value(counts, kind, valuation, memo) for kind in graph.wins[index]} 

416 for index, counts in enumerate(graph.counts) 

417 ] 

418 later = ([0.0] * len(graph.counts), [0.0] * len(graph.counts)) 

419 curve = [0.0] 

420 for _ in range(horizon): 

421 later = _points_sweep(graph, pools, total, later, worth) 

422 curve.append(later[0][0] / later[1][0] if later[1][0] else 0.0) 

423 return tuple(curve)

426def _curve(graph: _Graph, pools: list[list[int]], total: int, horizon: int, *, winning: bool) -> tuple[float, ...]: 

427 """The whole draws-remaining curve for one measure. 

428 

429 Because every draw sees the same pool, a hand's value turns only on how many 

430 draws are left and not on how many have gone. One sweep per draw therefore 

431 walks the entire curve, each entry being the value one draw deeper than the 

432 last. 

433 """ 

434 values = [1.0 if not winning and state else 0.0 for state in graph.ready] 

435 curve = [values[0]] 

436 for _ in range(horizon): 

437 values = _sweep(graph, pools, total, values, winning=winning) 

438 curve.append(values[0]) 

439 return tuple(curve)

442def _check_valuation(concealed: list[int], num_melds: int, valuation: Valuation) -> None: 

443 """Reject a valuation that does not describe the hand it is asked about. 

444 

445 The marks are checked against the hand as the caller passed it. A discard 

446 weighed inside may drop below its mark -- cutting the only copy of a marked 

447 five cuts the red one -- and the pricing clamps to the copies still held 

448 rather than rejecting the candidate. 

449 

450 Raises: 

451 ValueError: If the called sets do not match the meld count, or a red 

452 marking names a kind that is not a five or is not held. 

453 """ 

454 if len(valuation.melds) != num_melds: 

455 raise ValueError(f"valuation holds {len(valuation.melds)} melds, but the hand has {num_melds}") 

456 if not valuation.red_fives: 

457 return 

458 if len(valuation.red_fives) != NUM_KINDS: 

459 raise ValueError(f"red fives must be a count per kind, got {len(valuation.red_fives)}") 

460 for kind, reds in enumerate(valuation.red_fives): 

461 if reds and TileKind(kind) not in FIVE_KINDS: 

462 raise ValueError(f"kind {TileKind(kind)} cannot be red") 

463 if reds > concealed[kind]: 

464 raise ValueError(f"{reds} red {TileKind(kind)} marked, but the hand holds {concealed[kind]}")

467def _outlook( 

468 concealed: list[int], 

469 num_melds: int, 

470 max_draws: int, 

471 visible: Sequence[int] | None, 

472 player_count: int, 

473 beam: int | None, 

474 max_distance: int | None, 

475 valuation: Valuation | None = None, 

476 memo: dict[tuple, float] | None = None, 

477 *, 

478 validate: bool = True, 

479) -> Outlook: 

480 """The shared body behind both entry points. 

481 

482 ``validate`` is unset only for the per-candidate calls of a discard sweep, 

483 whose valuation was already checked against the whole hand: a candidate that 

484 cuts a marked five legitimately holds fewer copies than the mark. 

485 """ 

486 if max_draws < 0: 

487 raise ValueError(f"max draws must not be negative, got {max_draws}") 

488 if beam is not None and beam < 1: 

489 raise ValueError(f"beam must be at least one, got {beam}") 

490 if max_distance is not None and max_distance < 0: 

491 raise ValueError(f"max distance must not be negative, got {max_distance}") 

492 kinds = kinds_in_play(player_count) 

493 distance = shanten_counts(concealed, num_melds) 

494 if valuation is not None and validate: 

495 _check_valuation(concealed, num_melds, valuation) 

496 if max_distance is not None and distance > max_distance: 

497 blank = (0.0,) * (max_draws + 1) 

498 return Outlook(ready=blank, win=blank, points=blank if valuation else ()) 

499 graph = _graph(tuple(concealed), num_melds, player_count, max_draws, beam) 

500 pools, total = _unseen(graph, visible or [0] * len(concealed), kinds) 

501 if total < max_draws: 

502 raise ValueError(f"only {total} tiles are unseen, fewer than the {max_draws} draws asked for") 

503 return Outlook( 

504 ready=_curve(graph, pools, total, max_draws, winning=False), 

505 win=_curve(graph, pools, total, max_draws, winning=True), 

506 points=( 

507 _points_curve(graph, pools, total, max_draws, valuation, memo if memo is not None else {}) 

508 if valuation is not None 

509 else () 

510 ), 

511 )

514def hand_outlook( 

515 concealed: list[int], 

516 num_melds: int, 

517 max_draws: int, 

518 *, 

519 visible: Sequence[int] | None = None, 

520 player_count: int = 4, 

521 beam: int | None = 1, 

522 max_distance: int | None = 2, 

523 valuation: Valuation | None = None, 

524) -> Outlook: 

525 """The outlook for a resting hand played on as it stands. 

526 

527 ``visible`` counts the tiles known to be outside the hand -- every pond, every 

528 called meld, and the revealed indicators -- and must not include the hand 

529 itself, which is deducted from the unseen pool separately. 

530 

531 Args: 

532 concealed: Concealed tile counts indexed by kind, at resting size. 

533 num_melds: The number of called melds the hand holds. 

534 max_draws: The furthest draw to report, the horizon of the curves. 

535 visible: Counts by kind of tiles known to be outside the hand. Defaults 

536 to none visible. 

537 player_count: The number of players, which fixes the kinds in play. 

538 beam: The most hands to keep per improving draw, widest acceptance 

539 first, or ``None`` to keep every one. Keeping only the best is the 

540 default; keeping all is exact but far costlier away from ready. 

541 max_distance: The furthest from ready a hand may be and still be solved; 

542 beyond it both curves are flat zero. ``None`` solves at any distance. 

543 Cost rises about tenfold per step away from ready, so this is the 

544 control that bounds it. 

545 valuation: The table to price winning completions against. Given one, the 

546 ``points`` curve is filled; without one it stays empty. 

547 

548 Returns: 

549 The ready and win curves over zero to ``max_draws`` draws. 

550 

551 Raises: 

552 ValueError: If the hand is not of a legal resting size, if ``max_draws`` 

553 is negative or exceeds the unseen tiles, if ``beam`` is below one, if 

554 ``max_distance`` is negative, if a kind has more copies visible and 

555 held than exist, or if the valuation does not describe the hand. 

556 """ 

557 return _outlook(concealed, num_melds, max_draws, visible, player_count, beam, max_distance, valuation)

569 valuation: Valuation | None = None, 

570) -> dict[TileKind, Outlook]: 

571 """The outlook left behind by each discard from a hand holding a fresh draw. 

572 

573 Only the discards that leave the hand no further from ready are reported: a 

574 discard that gives ground is never the one being weighed, and solving it 

575 costs as much as solving a real candidate. Each result is exactly what 

576 ``hand_outlook`` reports for the hand that discard leaves. 

577 

578 Args: 

579 concealed: Concealed tile counts indexed by kind, at post-draw size. 

580 num_melds: The number of called melds the hand holds. 

581 max_draws: The furthest draw to report, the horizon of the curves. 

582 visible: Counts by kind of tiles known to be outside the hand. Defaults 

583 to none visible. 

584 player_count: The number of players, which fixes the kinds in play. 

585 beam: The most hands to keep per improving draw, widest acceptance 

586 first, or ``None`` to keep every one. 

587 max_distance: The furthest from ready a hand may be and still be solved; 

588 beyond it every curve returned is flat zero. ``None`` solves at any 

589 distance. 

590 valuation: The table to price winning completions against. Given one, the 

591 ``points`` curve is filled; without one it stays empty. 

592 

593 Returns: 

594 Each discard that holds the hand's distance to ready, mapped to the 

595 outlook of the hand it leaves. 

596 

597 Raises: 

598 ValueError: If the hand is not of a legal post-draw size, if ``max_draws`` 

599 is negative or exceeds the unseen tiles, if ``beam`` is below one, if 

600 ``max_distance`` is negative, if a kind has more copies visible and 

601 held than exist, or if the valuation does not describe the hand. 

602 """ 

603 counts = list(concealed) 

604 # The marks are checked against the whole hand here; each candidate below may 

605 # legitimately hold fewer copies than the mark, having cut the marked five. 

606 if valuation is not None: 

607 _check_valuation(counts, num_melds, valuation) 

608 memo: dict[tuple, float] = {} 

609 held = [kind for kind in kinds_in_play(player_count) if counts[kind]] 

610 after = discard_shantens(counts, num_melds, held) 

611 keeps = min(after.values()) 

612 outlooks = {} 

613 for kind in held: 

614 if after[kind] != keeps: 

615 continue 

616 counts[kind] -= 1 

617 outlooks[kind] = _outlook( 

618 counts, num_melds, max_draws, visible, player_count, beam, max_distance, valuation, memo, validate=False 

619 ) 

620 counts[kind] += 1 

621 return outlooks

629 player_count: int = 4,

639 visible: Counts by kind of tiles known to be outside the hand. Defaults
